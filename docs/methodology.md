# 模型与评价

## 估计什么

FundTrace 解释“最近基金收益由哪些行业收益组合解释”，系数作为收益口径的隐含行业暴露。它不是基金实际交易或持仓查询，不是未来收益预测器。

## 两步建模

首先整理披露持股、证监会行业配置与申万行业映射。对不完整披露利用重仓股及历史结构补全季度行业组合。分类并非一对一，尤其制造业内部行业分配依赖假设。

随后将基金净值优先转为复权净值日收益，与行业指数收益按日期对齐，每周拟合：

```math
\min_{\beta,c}\sum_t \widetilde w_t(y_t-X_t\beta-c)^2+\alpha\sum_j\beta_j,
\quad \beta_j\geq0,\quad\sum_j\beta_j\leq B.
```

实现是 NumPy FISTA，含约束投影与数值收敛检查。默认 window=120、half_life=40、alpha=1e-6，逐行业锚定关闭。时间权重为 0.5^(age/half_life)。

| 选择 | 目的 | 代价 |
|---|---|---|
| 滚动窗口 | 适应结构变化 | 短窗更敏感也更不稳定 |
| 时间衰减 | 重视近期信息 | 有效样本减少，容易跟随噪声 |
| 非负 | 多头权益场景下易解释 | 不适合复杂对冲策略 |
| Lasso | 控制冗余系数 | 收缩偏差、相关行业仍可替代 |
| 总量约束 | 限制不合理暴露 | 过低上限可能压制结果 |

稳定版本采用 legacy 上限：滞后模拟组合合计×1.05，上限0.98；无先验时0.95。没有将 B2 的 disclosure-cap 实验混入展示版本。

## 拟合质量不等于推断可信度

V1.4 将最新 R²、收敛情况形成的模型质量，与暴露总量差、结构差、主要行业异常等合理性规则结合。规则只限制等级，不提高等级，不改变系数。

真实历史示例中最新 R²=0.831、模型质量 A，但结果可信度 C。这个差异是产品设计的一部分：提示用户谨慎看待绝对比例。

## 评价边界

- R² 是窗口内收益拟合，不是持仓准确率。
- FULL 仍以持股数 >15 判断，不能证明完整披露；季度补全 MAE 依赖未经充分核验的真值。
- 实际公告日不足，模型使用工作日和自然日滞后近似；不声称已消除前视。
- 部分评分包含报告期后窗口，需独立外层样本外验证。
- 1.5σ 变化带与可信度等级是启发式规则，不是统计置信区间。
- Dashboard 的披露比较来自模拟结构，不等于独立确认的完整真实持股。
- 老报告保留历史 A 级；V1.4 Dashboard 的结果等级可更低，下载报告需结合界面阅读。
- 标定候选保持 production_eligible=false，不自动替换正式参数。
- 个股因子、港股/QDII、多基金泛化没有在本次产品验收中验证。

下一步应先补真值和时点，再比较披露延续、OLS、非负无 L1 和当前方案。没有证据证明 Lasso 对所有基金最优。
