# Public repository scope

This repository is a standalone product portfolio snapshot, not a complete research-data distribution.

## Included

- FastAPI backend (api), React frontend source, Python model library and orchestration.
- Python/frontend tests, including synthetic test fixtures defined in code.
- Architecture, methodology, product workflow and validation boundaries.
- Four selected images: actual historical Dashboard, actual model diagnostics, actual generated result plot, and an explanatory workflow diagram.

## Excluded

Original research data are not included: no base, funds, output, original JavaScript fund downloads, market databases, CSV research baselines or raw disclosure archives. No virtual environment, node_modules, runtime logs, personal machine reports, local absolute user paths, internal company documents or original Git history.

The original development repository is retained without changes. Source provenance: V1.4 product branch feat/v1.4-credibility-regrade, source commit 075fc12d9d7f8f84f1325777884e9c1571532a04.

Five original tests require excluded research data or baselines and are explicitly skipped when absent. Skips are not reported as passes. Synthetic tests demonstrate implementation behavior, not actual fund accuracy.

Screenshots show a historical locally verified run; they are not a hosted service or a claim of current market information. No corporate endorsement, production deployment, efficiency improvement or investment return is asserted.

Third-party libraries retain their respective licenses. Dependencies are installed through package managers; no third-party CDN media or bundled dependency binaries are redistributed here. Public visibility alone is not a grant of rights to excluded data.
